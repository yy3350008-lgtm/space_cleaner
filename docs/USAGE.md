# 使用说明（V2 小白版）

**压缩优先 · 删除手动**

## 1. 启动

直接运行 `SpaceCleaner.exe`，或在源码目录执行：

```powershell
C:/Users/25082/AppData/Local/Programs/Python/Python313/python.exe main.py
```

如果你拿到的是打包后的版本，不需要 Python 和编辑器，直接双击 `SpaceCleaner.exe`，或者在终端里进入目录后运行 `SpaceCleaner.exe` / `run_space_cleaner.bat` 就行。

启动后会看到 9 个选项：

1. `👉 一键安全清理（保守模式，扫描下载与桌面）`
2. `👉 自定义兼推荐清理（标准模式，所有磁盘可选）`
3. `👉 自主加入隔离箱（手动选文件）`
4. `👉 极限释放（压缩后清理隔离副本，需三重确认）`
5. `👉 查看物理隔离箱（系统文件夹）`
6. `👉 查看『隔离箱』与历史恢复`
7. `👉 手动清理到期隔离副本`
8. `👉 手动清空隔离箱（立即执行）`
9. `👉 退出`

## 2. 最简单操作

1. 选 `一键安全清理`
2. 等待扫描结束
3. 看空间收益面板（能腾出多少空间）
4. 确认后程序会把文件先搬到隔离箱并生成 ZIP
5. 随时可恢复，不会直接暴力删除

## 2.1 自定义目录中的“智能扫描并建议压缩”

1. 进入 `自定义兼推荐清理`
2. 目录动作只负责导航，文件动作才加入隔离候选
3. 在目录操作里选择 `智能扫描并建议压缩`
4. 程序会列出命中的推荐候选，一次确认后直接隔离归档
5. 全流程不会自动删除文件

提示：需要自定义路径时，请直接选择文件夹。助手会自动分析这个文件夹及其子目录。

## 3. 程序如何保护你

1. 不会在你确认前动文件
2. 空间不够时自动中止（预留 20% 余量）
3. 文件被占用会自动跳过
4. ZIP 完整性校验失败会立刻中止，不改状态
5. 删除隔离副本时走回收站，不做永久删除

## 4. 报告文件

1. 预览报告：`preview_*.txt`
2. 操作清单：`manifest_*.txt` 和 `manifest_*.csv`

所有报告都是 `utf-8-sig`，记事本可直接看中文。

## 5. 可调配置

编辑 `config.json` 常用项：

1. `scan_targets` 扫描目录（程序会自动补充推荐目录，例如可检测到的微信文件目录）
2. `quarantine_dir` 隔离箱目录
3. `cleanup_mode` 默认清理模式
4. `quarantine_cleanup_after_zip_days` 归档后多久提示可清理隔离副本

## 6. 常见疑问

1. 为什么没立刻释放全部空间？
程序默认先隔离再归档，这是为了可恢复。后续可在到期提醒中清理隔离副本。

2. 为什么某些文件没处理？
可能命中排除规则、被系统占用，或权限不足。

3. 断电后会不会乱？
不会。状态机会记录 `in_progress/quarantined/archived`，下次启动会提示处理。

4. 我不会填路径怎么办？
不用填。自定义深度清理支持目录浏览与文件选择，不要求手工输入路径。

## 7. 极限释放模式（新增）

适用场景：你明确要最大化释放空间，并接受“归档后清理隔离副本”。

执行门槛（缺一不可）：

1. 先完成扫描、隔离、ZIP 归档和校验
2. 通过十项安全检查（状态文件、归档存在性、ZIP 完整性、隔离副本可访问等）
3. 三重人工确认：阅读风险确认、输入口令 `极限释放`、最终确认

防御边界：

1. 任一关键检查失败会自动阻断
2. 归档损坏或缺失时绝不清理隔离副本
3. 清理动作仍走回收站策略，不做永久删除
