# 最终发布清单（SpaceCleaner V2）

## 1. 你手里有哪些可分发文件

1. 安装版（推荐给普通用户）
- 路径：`release/installer/SpaceCleaner_Setup_1.0.0.exe`
- 特点：有安装向导，体验接近商业软件。

2. 便携版（推荐给免安装用户）
- 路径：`release/SpaceCleaner_Portable.zip`
- 特点：解压即用，不写系统安装信息。

如果用户没有 Python 环境，优先发这两种打包版本，不建议直接发源码目录。

## 2. 给用户时怎么说（可直接复制）

### 安装版用户
1. 双击运行 `SpaceCleaner_Setup_1.0.0.exe`
2. 按提示安装完成
3. 从桌面快捷方式启动“释放空间助手”

### 便携版用户
1. 解压 `SpaceCleaner_Portable.zip`
2. 打开解压目录
3. 双击 `启动_释放空间助手.bat`

如果用户只会用终端，也可以在该目录里直接运行 `SpaceCleaner.exe` 或 `run_space_cleaner.bat`，不需要编辑器。

## 3. 小白用户首次使用（最短路径）

1. 启动后选：`👉 一键安全清理（保守模式，扫描下载与桌面）`
2. 看扫描结果里的空间收益
3. 确认后再执行搬运和归档
4. 需要时可在“查看隔离箱”中恢复

如果用户明确要求“压缩后尽量只留一份”，可选：
1. `👉 极限释放（压缩后清理隔离副本，需三重确认）`
2. 必须逐步确认，输入口令后才执行
3. 任一关键检查未通过会自动阻断

## 4. 安全边界（必须告知用户）

1. 工具不会在确认前自动改动文件。
2. 文件先进入隔离区，支持恢复。
3. 归档校验失败不会删除隔离副本。
4. 清理走回收站策略，避免误删不可逆。

## 5. 你这边发布前最后检查（30秒）

1. 安装包是否存在：`release/installer/SpaceCleaner_Setup_1.0.0.exe`
2. 便携包是否存在：`release/SpaceCleaner_Portable.zip`
3. 便携目录中无日志残留：`release/SpaceCleaner_Portable/_internal/*.log`（应为空）

## 6. 版本更新时的固定流程

1. 代码变更后先跑回归验证（建议至少 3 轮）
2. 重打包安装版与便携版
3. 清理构建中间垃圾（缓存、临时验证脚本、旧产物）
4. 仅保留源码与最终交付件

## 7. 维护者备注

- 若用户只想“最稳”：发安装版。
- 若用户无管理员权限：发便携版。
- 若企业环境杀软严格：优先安装版并建议加入排除路径。
